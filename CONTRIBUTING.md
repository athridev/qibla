# Contributing

Thank you for helping improve Qibla.

1. Fork the repository and create a focused branch.
2. Keep the app dependency-light and usable on mobile browsers.
3. Preserve Arabic right-to-left support and keyboard/touch accessibility.
4. Do not add analytics, location storage, compass access, music, faces, or animal imagery.
5. Verify geodesic changes against known locations and edge cases such as the antimeridian.
6. Open a pull request explaining the user-visible change and how you checked it.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
